# Git workflow and login test design

This practice assignment was performed on a local macOS machine. The GitHub repository was created after the local initial commit, second commit, feature branch commit, explicit merge, ignore rules, and revert operation.

- `index.html` and `about.html`: minimal HTML project.
- `.gitignore`: ignores `*.log` and `temp/`.
- `git_commands.txt`: commands and explanations.
- `login_test_cases.json`: designed test cases, fixtures, and assumptions. These cases are a test design; no login application was supplied or executed.

The `feature` branch is retained. The main history includes an explicit merge commit and a revert that preserves the undone commit. Both branches are pushed.

Public repository: https://github.com/ADITYAKUMARRAI2007/git-workflow-login-test-design
